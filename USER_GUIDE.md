# 🚀 AeroVerse Platform - Guide d'Utilisation

## 📖 Vue d'ensemble

AeroVerse est une plateforme éducative complète dédiée à l'aérospatiale et la technologie spatiale. Elle combine simulation 3D, construction interactive, apprentissage adaptatif et assistance IA.

## 📚 Modules Principaux

### 1. **Simulation VR** 🌌
- **Accès** : Cliquez sur "Simulation" dans la navigation
- **Fonctionnalités** :
  - Visualisez des environnements spatiaux en 3D
  - Navigation libre avec clavier/souris
  - Informations en temps réel sur les destinations
  - Visualisation d'orbites et de trajectoires

### 2. **Musée Virtuel** 🏛️
- **Accès** : Cliquez sur "Musée" dans la navigation
- **Fonctionnalités** :
  - Exploration de modèles 3D de satellites et vaisseaux
  - Descriptions détaillées de chaque exhibit
  - Hotspots interactifs avec informations contextuelles

### 3. **Builder (Constructeur)** 🔧
- **Accès** : Cliquez sur "Builder" dans la navigation
- **Onglets disponibles** :
  - **Bibliothèque** : Liste des composants disponibles
  - **Zone d'Assemblage** : Construisez votre vaisseau
  - **Vision** : Capture et analyse des composants
- **Workflow** :
  1. Sélectionnez des composants dans la bibliothèque
  2. Assemblez-les dans la zone de travail
  3. La Vision par Ordinateur identifie automatiquement les pièces
  4. Sauvegardez votre création

### 4. **Éducation** 📚
- **Accès** : Cliquez sur "Éducation" dans la navigation
- **Onglets disponibles** :
  - **Catalogue** : Parcourez les cours disponibles
  - **Leçons** : Contenu interactif avec animations
  - **Quiz** : Évaluations interactives
- **Progression** : Votre avancement est sauvegardé automatiquement

### 5. **AI Tutor** 🤖
- **Accès** : Cliquez sur "AI Tutor" dans la navigation
- **Onglets disponibles** :
  - **Chat** : Conversation en temps réel avec l'IA
  - **Langue** : Sélectionnez Français ou Anglais
  - **Historique** : Consultez vos conversations antérieures
- **Utilisation** :
  1. Tapez votre question dans le champ de saisie
  2. Appuyez sur Entrée ou cliquez sur l'icône d'envoi
  3. L'IA répond en temps réel

### 6. **Profil Utilisateur** 👤
- **Accès** : Cliquez sur l'icône "Profil" dans la navigation
- **Fonctionnalités** :
  - Visualisez vos informations personnelles
  - Modifiez vos préférences linguistiques
  - Consultez votre progression globale
  - Connectez/Déconnectez-vous

### 7. **Panneau d'Administration** ⚙️
- **Accès** : Cliquez sur l'icône "Admin" (administrateurs uniquement)
- **Sections** :
  - **Gestion Utilisateurs** : Gérez les comptes et permissions
  - **Assets 3D** : Gérez les modèles 3D
  - **Contenu** : Modifiez les modules éducatifs
  - **Configuration** : Paramètres système
  - **Services Externes** : Configuration des APIs
  - **Monitoring** : Surveillance des performances

## 🔐 Authentification

### S'inscrire
1. Cliquez sur le bouton "Connexion" dans la navigation
2. Sélectionnez l'onglet "S'inscrire"
3. Remplissez le formulaire (nom, email, mot de passe)
4. Cliquez sur "S'inscrire"

### Se Connecter
1. Cliquez sur le bouton "Connexion" dans la navigation
2. Entrez votre email et mot de passe
3. Cliquez sur "Se connecter"

## 🐛 Dépannage

### La page ne charge pas
- Vérifiez votre connexion Internet
- Rechargez la page (F5 ou Ctrl+R)
- Videz le cache navigateur

### Les modèles 3D ne s'affichent pas
- Vérifiez que votre GPU supporte WebGL
- Mettez à jour votre navigateur
- Réduisez la qualité graphique dans les paramètres

### L'IA ne répond pas
- Vérifiez que vous êtes connecté à Internet
- Vérifiez votre clé API OpenAI (admins)
- Attendez quelques secondes et réessayez
